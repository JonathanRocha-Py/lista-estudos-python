# 📋 Gerenciador de Lista de Estudos

## 📌 O que é este projeto
Sistema simples de lista com funcionalidades completas: adicionar, listar, marcar concluído e remover itens. Demonstração de lógica de programação aplicada com estruturas de dados.

## 🎯 O que aprendi
- Trabalhar com listas e dicionários em Python
- Estruturas de repetição (for, while)
- Estruturas condicionais (if/else)
- Funções com parâmetros e retorno
- Manter controle de status de informações

## 🛠️ Tecnologias
- Python 3.x

## ▶️ Como usar
```bash
python3 lista_estudos.py

✅ Funcionalidades
- ✅ Adicionar novo item com descrição e data
- ✅ Listar todos os itens com status
- ✅ Marcar como concluído
- ✅ Remover item
- ✅ Exibir contador: total / concluído / pendente
